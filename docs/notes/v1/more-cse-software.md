### **Finite Elements, Discretizations & PDEs**

> * **FEniCS** — Solvers for partial differential equations via finite element discretizations; host repository on [FEniCS Project on GitHub](https://github.com/fenics?utm_source=gemini).  
> * **deal.II** — C++ finite element library with support for adaptive meshes and complex geometries; source repository on [deal.II on GitHub](https://github.com/dealii/dealii?utm_source=gemini).  
> * **MFEM** — High-order finite element discretizations for electromagnetic, fluid, and structural simulations; official platform at [MFEM Website](https://mfem.org?utm_source=gemini).  
> * **DUNE** — Modular C++ grid framework and discretization library; available at [DUNE Project](https://dune-project.org?utm_source=gemini).  
> * **FiPy** — Finite volume PDE solver built in Python; hosted by NIST at [NIST CTCMS](https://www.ctcms.nist.gov?utm_source=gemini).  
> * **MOOSE** — Multiphysics framework developed by Idaho National Laboratory; hosted at [MOOSE Framework](https://mooseframework.inl.gov?utm_source=gemini).  
> * **libMesh** — Parallel adaptive finite element library developed by the Oden Institute; hosted at [libMesh on GitHub Pages](https://libmesh.github.io?utm_source=gemini).  
> * **hIPPYlib** — Python library for inverse problems and Bayesian uncertainty quantification; official site at [hIPPYlib on GitHub Pages](https://hippylib.github.io?utm_source=gemini).  
> * **Dedalus** — Flexible spectral PDE solver written in Python; documentation at [Dedalus Project Docs](https://readthedocs.io?utm_source=gemini).

### **Computational Fluid Dynamics & Aerodynamics**

> * **SU2** — Aerodynamic shape optimization, multiphysics, and CFD code; official site at [SU2 Code](https://su2code.github.io?utm_source=gemini).  
> * **Nek5000 / NekRS** — High-order spectral element code for fluid dynamics and turbulence; hosted by Argonne National Laboratory at [Argonne National Laboratory](https://www.anl.gov?utm_source=gemini).  
> * **AMReX** — Block-structured adaptive mesh refinement framework for fluid and plasma dynamics; hosted on [GitHub](https://github.com?utm_source=gemini).  
> * **SAMRAI** — Structured adaptive mesh refinement infrastructure developed by LLNL; hosted on [GitHub](https://github.com?utm_source=gemini).  
> * **WarpX** — Advanced particle-in-cell code for plasma physics and accelerator modeling; hosted on [GitHub](https://github.com?utm_source=gemini).
