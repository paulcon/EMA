# Plans

One plan per build step, written (by Claude Code in plan mode, or by you) before the step starts, reviewed
by you, and committed. Copy `_template.md` to `NN-short-title.md`.

- A step implements accepted specs only. The plan names them.
- A plan ends with a stop condition. Claude stops there and waits for review.
- The status block at the top is updated as the step goes; when the step is done, the plan stays as a record.
- One step at a time. The next plan is written after the last step has been reviewed and merged.
